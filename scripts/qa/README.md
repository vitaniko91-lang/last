# QA

## `npm run qa:responsive`

Замер живого движка на 1920, 768 и 375 по шести маршрутам. Проверяет две вещи:
горизонтальное переполнение (`scrollWidth` против `clientWidth`) и зоны нажатия
меньше 40×40.

Почему замер, а не снимок: `chrome --headless --window-size` задаёт размер
СНИМКА, а не layout viewport. Страница верстается шире, снимок её просто
обрезает — и обрезанный текст читается как переполнение, которого нет.
Скриншот здесь детектор, вердикт даёт число.

Перед каждым замером скрипт считает кадры за секунду. Ниже 30 — страница не
композитится, и никакой вывод о ней не действителен; скрипт падает, а не
печатает цифры, которым нельзя верить.

Против задеплоенного адреса:

```
BASE_URL=https://last-... npm run qa:responsive
```

## `npm run qa:shots`

Снимки шести экранов на 1440 и 390 в указанную папку. Конфигуратор доводится
до состояния результата, иначе снимок покажет первый шаг.
